Contact Management System

About the Project

We developed a Contact Management System using the MVC (Model-View-Controller) architecture. The system allows users to add, view, update, search, and delete contacts easily.

Features

• Add new contacts
• View saved contacts
• Update contact information
• Search for contacts
• Delete contacts
